# 健康与计划交互更新设计

## 目标

把“今日”变成可提前完成未来计划的执行面板；将健康页改成 DeepSeek 问诊对话、喝水与睡眠提醒及 Apple 健康运动记录；简化吃什么录入并支持菜品照片；所有计划通过系统通知提醒。

## 方案

### 计划执行

`SchedulePlanner.reminders` 保持生成未来提醒的纯函数，但 `AppStore` 的展示窗口扩展为从当前日开始的 7 天。`TodayView` 按日期分组展示事件和生活提醒，每一条均可立即标记完成、稍后或跳过；记录 ID 与计划日期绑定，因此提前完成未来计划不会生成重复提醒。事件提醒仍按开课前 15 分钟执行。

### 健康数据与提醒

删除报告文件导入和旧的 `AdviceResponse` 确认流程。新增可持久化的 `HealthChatMessage`，`AIService` 使用 DeepSeek Chat Completions 发送完整对话并返回文本。健康页显示对话历史与输入框，明确提示仅作生活建议、不替代诊疗。

`HealthProfile` 保留睡眠时长、喝水间隔和每次毫升数；喝水提醒默认为开启并允许用户编辑两个数值。运动不再生成计划提醒，Apple Health 查询结果和手动运动记录合并展示在当天；手动记录包含类型、分钟、距离。睡眠计划取次日最早的非全天课程或自定义事件，按准备时间和睡眠时长倒推起床/入睡；睡前 30、20、10 分钟各生成一次系统提醒。

### 吃什么

`Dish.ingredientsVerified` 删除，转盘只根据过敏原、忌口和近期重复过滤。`Dish` 增加可选 `photoPath`，图片复制到应用支持目录的 `DishPhotos` 子目录；读取失败时仍显示文字菜名。新增菜品时可拍照或从照片库选择，照片不是必填。

### 通知

`NotificationService` 统一接收未来 7 天的计划队列，设置变更后自动清理并重排；请求权限仍由用户首次触发。通知内容包含日期和具体指标，睡眠三次提醒使用不同 ID，避免互相覆盖。

## 数据兼容与错误处理

`AppSnapshot.schemaVersion` 升至 2，解码旧版本时补默认值：喝水开启、运动提醒关闭、聊天为空、菜品无照片、手动运动为空。图片复制失败只显示错误横幅，不阻止保存文字菜品。DeepSeek 网络错误显示可重试横幅，不丢失已输入消息；API Key 只从钥匙串读取。

## 验证

新增核心测试覆盖：未来提醒可提前完成、睡眠三次提醒、喝水字段默认值、运动记录合并、旧快照迁移、菜品照片路径可选和转盘不再依赖配料确认。现有 ICS、节日和通知队列测试必须继续通过；之后用 Xcode 真机构建并确认无编译错误。
